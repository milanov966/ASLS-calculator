# Анализ и синтез на логически схеми (C++17)

Конзолно приложение за решаване на задачи с операциите **инверсия, конюнкция и дезюнкция**.

## Компилиране
```
g++ -std=c++17 -O2 -o logic main.cpp
./logic
```
или `cmake -B build && cmake --build build`.

## Записване на изрази
| Операция | Запис |
|---|---|
| Инверсия | `!a`, `~a`, `a'` (допускат се няколко: `!!!a`) |
| Конюнкция | `*`, `.`, `&` или слято (`ab`) |
| Дезюнкция | `+` или `|` |
| Скоби, константи | `( )`, `0`, `1` |

## Типове задачи
1. **Свързване на логическа схема** – списък от елементи (НЕ, И, ИЛИ) и схема като дърво (фиг. 1).
2. **Алгебрични преобразувания** – пълно решение стъпка по стъпка със закони: комутативен, асоциативен,
   дистрибутивен, поглъщане, слепване, Де Морган (+ двойно отрицание, идемпотентност, допълнение).
3. **Доказване на тъждества** – напр. `a+!a*b=a+b`: `a+ā·b = (a+ā)(a+b) = a+b`. Работи и с няколко инверсии на една променлива.
4. **Функция** – напр. `f(x,y,z)=(x+y)(!z+y)`: таблица на истината, нули/единици, минтерми, макстерми,
   СДНФ/СКНФ и алгебрично решение като във фиг. 2 и 3 (`f = ΠM(...)`).

Опция 5 в менюто сменя стила на инверсията между `!a` и `a̅`.
